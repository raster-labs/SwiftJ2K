What the helper checks
1. Both instrumented partitions and the ordinary reference have successful root
   result receipts, unchanged and identical complete source manifests, and raw
   log hashes matching those receipts. Frozen test source used for display-name
   binding must match every recorded Tests/ file hash.
2. Every XCTest declaration has its exact qualified start and completion once.
   Swift Testing XML has every canonical declaration once, with no failure/error.
   The exact framework union equals the intended inventory for each run.
3. Every Swift Testing start/completion display is bound to one canonical ID.
   Untitled signatures bind directly; simple first-argument @Test string literals
   bind to a unique module/function ID, preserving file, line, literal and hash.
   Unknown title syntax, duplicate names or ambiguous functions fail explicitly.
4. The exact argument-value multiset for each parameterized declaration matches
   the ordinary run, and each run reports the same successful aggregate case
   count as its argument-start count. Order is irrelevant; multiplicity is not.
5. Partition IDs are disjoint and their union is the complete ordinary inventory.
   Every canonical status and parameter completion count matches the ordinary
   reference; newly missing or skipped tests fail. Existing skipped declarations
   are explicitly retained as unexecuted and cannot become successful oracle
   evidence. Actual known-issue events stop automatic proof for manual review.
6. Real sanitizer warning/error markers fail. Unrecognized/interleaved runtime
   event lines fail rather than silently disappearing. An intact Unicode event
   suffix after a prefixed compiler warning is readable; an event spliced in its
   middle remains unresolved. All known/skip/unexecuted text remains in the proof.
7. New wrapper receipts with native_streams require capture_complete=true, joined
   capture threads, no capture_errors and wrapper_exit_code=0. Both exact raw file
   hashes and byte counts are checked. Execution events come from native.stdout;
   both stdout and stderr are scanned for sanitizer reports. The merged native.log
   is still hashed and retained. Historical receipts without streams use the strict
   merged-log parser; no historical stream identity is invented.

Limits and manual checklist
- This is purpose-built for observed Apple Swift 6.4 report formats; hosted
  Swift 6.3.3 needs actual format/identity review. Format changes are explicit
  errors, not evidence that tests themselves failed or that omissions are safe.
- The reporter does not emit per-argument completion identities. Exact argument
  starts plus the successful declaration's matching case count establish the
  runner's completion statement for those cases, not individual completion-event
  receipts. If stronger evidence is required, obtain structured framework events;
  do not claim these XML files contain records they do not contain.
- Review every extracted custom title binding against its frozen @Test declaration
  if syntax/overloading is nontrivial. Unsupported interpolated/raw/multiline titles
  or conditional source declarations require an explicit reviewed mapping or parser
  extension. This limited text reader is not a general Swift parser.
- Inspect retained skipped/known-issue/raw oracle lines and environment separately.
  A framework test that conditionally avoids a tool internally can still report
  passed. Neither framework coverage nor this helper establishes independent peer
  availability, exact tool execution, combined Part10+15, native 3D JPIP, repository
  WebSocket binding, full38 synthesis/output or multiple-active-HT-set qualification.
- Source identity is the wrapper's full file manifest, not a Git tree or a compiled
  binary proof. Keep command/compiler/CLI binding and artifact receipts alongside it.
- Complete partitioned sanitizer coverage is not a passing fully concurrent
  cross-target sanitizer run. The ordinary full concurrent gate remains required.
- Retain previous failed full07/fullTSan05 evidence. No whole R3 acceptance, waived
  independent gate or merge recommendation is issued by this helper.
