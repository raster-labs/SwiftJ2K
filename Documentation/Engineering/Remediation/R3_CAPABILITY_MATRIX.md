## Evidence convention

- **Source-reviewed** means a separate reviewer inspected the recorded immutable input; it is not an executed test or peer result.
- **Focused execution** applies only to the receipt's source, test selection, fixture identities and environment. `candidate-core-asan-01` passed 44 tests; it is not complete R3 sanitizer qualification.
- **Independent peer evidence** identifies the actual independently implemented decoder/protocol endpoint and unchanged bytes it consumed. Header adaptation, patched diagnostic decoders and separately written synthesis are disclosed as narrower diagnostics.

### Portable HTTPS and request-close boundary

The shared Darwin/FoundationNetworking delegate path admits observable headers, incoming callback data, old/new accumulation and the final body copy. Opaque Foundation/TLS/header/cache/queued callback storage cannot be preadmitted by this accumulator. Geometric-growth tests establish the reported copy-work bounds only for their specified one-byte fixtures, not a universal linear-work constant. The serial delegate queue has an explicit request service class matching the existing deadline queue; this is not a hard scheduling guarantee.

`JPIPTransport.close()` cancels and joins captured HTTP/HTTPS owners and invokes WebSocket disconnect. Terminal WebSocket reader/timeout callbacks may finish later. Generation checks prevent retired results from restoring a socket or channel path. HTTP completion means finite I/O and locked result publication, not physical thread exit; blocking DNS remains a qualification limit. HTTPS completion follows task completion, session invalidation and the serial delegate-queue tail; a separate deinitialisation observation checks eventual release. The new URLProtocol, scripted callback and loopback tests remain harness coverage: they do not establish real TLS behaviour, every higher-level client interleaving, or independent JPIP interoperability. Failed 09–14 receipts and their diagnostic observer limitations are retained. Exceptional WebSocket fixture cleanup uses a bounded completion observation with suppressed secondary failure, not an unconditional join guarantee.
